# Stickman Zombie Shooter
A survival game made with Raylib.

## Installation
Install with `make` command. Change directory to root repo and type `make` to build executable.
```bash
make
./zombieshooter
```

## Controls
- quit: `ESC`
- walk: `A` and `D`
- reload: `R`
- check ammo: hold `R`
- select fire: `X`
- change weapon: `Q`
- shoot: click
- restart game (when dead): `R`
